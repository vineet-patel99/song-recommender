Basic Full stack app for a music recommendation algorithm, used Content-Based-Filtering to narrow down 5 similar results that fit a user's music preferences. a simple project to get my feet wet on full stack development.
## Comments ##
Used GPT 5.4 to come up with a react template, using that template to further enhance the user experience, potentially making this an extension so that users who are connected with last.fm or another music tracking app can find recommendations based on what they are currently listening as well as inputting certain songs.
